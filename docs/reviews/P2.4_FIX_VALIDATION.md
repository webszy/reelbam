### 实际重启测试的故障边界

1. 在临时 Miniflare D1 安装只针对 output asset INSERT 的失败 trigger。
2. 创建 Mock 任务，由真实 consumer 经 Queue 执行到 R2 对象存在、D1 仍 storing。
3. 删除临时故障 trigger，销毁 Miniflare/workerd；Queue 内存丢弃。
4. 使用同一临时 D1/R2 持久目录新建运行进程，确定性推进已持久化租约到过期，再由真实 dispatcher 补发。
5. 断言 succeeded、一条资产、原 request ID 和唯一 attempt、余额 4、唯一 actual=0 USD。
6. R2 读回字节/hash 相同；再次用不同字节向已引用 Key 写入，条件写保护原对象。
7. 再注入 Outbox INSERT 失败，断言任务和扣费整批回滚。

测试为等待租约省略了真实 30 秒 sleep，改用临时数据库的过期时间注入；没有改生产租约策略。本地 Queue 不支持真实 Consumer concurrency，SQLite 的交错/worker_threads 结果仍不能替代线上多 isolate 验证。
